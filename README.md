## 概述

**pig-ui** 是一个为 PIGCLOUD 微服务开发平台开发的前端项目。它利用了现代 Web 技术，包括 Vue.js 3、Element Plus 和 Vite，提供了一个健壮且高效的开发环境。

## 核心依赖

| 依赖 | 版本 |
| --- | --- |
| Vue | 3.5.45 |
| Element Plus | 2.13.7 |
| Vite | 8.1.6 |
| TypeScript | 4.9.5 |
| Tailwind CSS | 3.4.19 |

## 快速开始

### 先决条件

- **Node.js**: 版本 22.12.0 或更高。
- **npm**: 版本 7.0.0 或更高。

PIG 提供了详尽的部署文档 👉 [docs.pig4cloud.com/open](https://docs.pig4cloud.com/open)，涵盖开发环境配置、服务端启动、前端运行等关键步骤。

- 现代浏览器的最后两个版本。
